# LifeFlow 桌面版发布目录

本仓库用于发布 LifeFlow（时流）桌面版的安装程序与自动更新清单。

## 下载

最新版本发布于 Releases 中的 `desktop-latest`。

| 文件 | 说明 |
| --- | --- |
| `LifeFlow-Setup.exe` | Windows 安装程序 |
| `latest.yml` | 自动更新清单，客户端据此判断是否存在新版本 |
| `LifeFlow-Setup.exe.blockmap` | 增量下载所需的块索引文件 |

## 系统要求

Windows 10 或 Windows 11（64 位）。

## 安装

安装程序尚未申请代码签名证书，首次运行时 Windows SmartScreen 可能显示安全提示。请依次选择「更多信息」与「仍要运行」以完成安装。

安装程序默认安装在当前用户目录下，无需管理员权限。安装过程中可以更改安装位置，但所选目录必须对当前用户可写，否则安装将中止并提示原因。

## 自动更新

应用启动后会在后台检查并下载新版本，下载完成后提示用户重启以完成安装。更新来源为本仓库的 `desktop-latest`。

## 常见问题

### 启动时提示「Windows 正在查找 LifeFlow.exe」

说明开始菜单或桌面上的快捷方式指向的安装目录中没有主程序文件。常见原因是安装目录对当前用户不可写（例如该目录由管理员创建，或位于系统保护的路径下），导致文件未能写入。

处理方法：

1. 在 Windows 的「设置 → 应用」中卸载 LifeFlow；
2. 重新运行安装程序，使用默认安装位置，或选择一个当前用户可写的目录；
3. 如确需安装到受保护目录，请右键选择安装程序，以管理员身份运行。

此问题已在 0.1.25 版本中处理：安装程序会在写入前检查目录权限，无法写入时直接中止并说明原因，不再产生指向空目录的快捷方式。

## 数据存储

用户数据保存在 `%APPDATA%\LifeFlow` 目录。卸载程序不会删除该目录，如需彻底清除请手动删除。
